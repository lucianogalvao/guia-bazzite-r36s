# Zelador Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uma página (PWA) servida pelo PC Bazzite, aberta pelo iPhone no Wi-Fi de casa, com botões para as correções conhecidas e um chat com um modelo local que só age por ferramentas fixas e com aprovação na tela.

**Architecture:** Servidor HTTP em Python **só com a biblioteca padrão**, rodando como serviço de usuário do systemd. Os botões chamam funções fixas (`acoes.py`), as mesmas do [12 · Comandos](../../bazzite/12-comandos.md). O chat fala com o Ollama (contêiner Podman com GPU via CDI, porta só em `127.0.0.1`). Ações que mudam arquivos viram **propostas** guardadas no servidor e só são executadas por um `POST /api/aprovar/<id>` vindo da página. Todo acesso ao sistema (comandos, leitura de arquivos) passa por um `Executor` injetável, para os testes rodarem no Mac sem o Bazzite.

**Tech Stack:** Python ≥ 3.10 (stdlib: `http.server`, `json`, `subprocess`, `urllib`, `unittest`, `hashlib`, `secrets`), Ollama em Podman Quadlet, modelo `qwen3:8b` (Q4), HTML/CSS/JS puro (sem build).

**Spec:** [docs/superpowers/specs/2026-11-12-zelador-design.md](../specs/2026-11-12-zelador-design.md)

## Global Constraints

- Bazzite imutável: nada de `rpm-ostree`/`dnf`/`sudo`. Tudo em `~`, Podman de usuário e systemd `--user`.
- Python: **só stdlib**, compatível com 3.10 (Mac) e 3.15 (Bazzite). Sem `pip`.
- Rede: servidor em `0.0.0.0:8787` (LAN). Ollama publicado **só** em `127.0.0.1:11434`.
- Textos da interface e respostas do modelo em **português do Brasil**.
- O modelo **nunca** roda shell livre: só ferramentas do registro (`ferramentas.py`).
- Tudo que move, extrai, copia ou apaga arquivos é uma **proposta** e precisa de "Aprovar". Proposta que apaga precisa de uma segunda confirmação (`confirmar_apagar: true`).
- Nunca montar, escrever ou sequer chamar `mount` no `ROOTFS` (btrfs) do cartão do R36S.
- Nunca mover ou apagar arquivo de torrent ativo do qBittorrent.
- Botões funcionam com o Ollama desligado.
- Modelo: `keep_alive` de `5m`. Antes de carregar, checar se há jogo usando a GPU e avisar.
- Arquivos do modelo em `/var/mnt/jogos/ollama`.
- Sem dados pessoais no repositório (IP, usuário, PIN): use os marcadores do README.

## Review Focus

1. **iPhone travando ou fechando a página no meio de uma tarefa longa** → a tarefa continua no servidor e a página, ao reabrir, mostra o progresso (teste em Task 4: tarefa sobrevive sem cliente; Task 9: `GET /api/tarefas` lista as em andamento).
2. **Dois toques em "Aprovar"** (toque duplo, rede lenta) → a proposta executa uma vez só (teste em Task 8: `test_aprovar_duas_vezes_executa_uma`).
3. **Nome de arquivo com espaço, vírgula, colchete ou aspas** (padrão dos downloads: `Jogo (World) (En,Ja) [0100...]`) → comandos montados como lista de argumentos, nunca string de shell (teste em Task 5: `test_plano_com_nome_estranho`).
4. **Ollama fora do ar ou demorando** → o chat responde "modelo indisponível" em até 10 s de conexão, e os botões seguem funcionando (teste em Task 7: `test_ollama_fora_do_ar`).
5. **Cartão do R36S com `ROOTFS` montado, ou sem `EASYROMS`** → a cópia é recusada com uma mensagem clara (teste em Task 6: `test_recusa_com_rootfs_montado`).
